# 按需补齐图层 / layer_completion

Use only when the real human requests hidden/missing-part completion. Clean extraction, global background removal and reconstruction are different tasks. Static hidden=unfilled is valid; it must not trigger this route. Animation alone is not blanket permission to invent unseen surfaces. If movement exposes gaps, explain the need and clarify scope before dependent painting.

## Analyze before filling
Inspect current source/composite/isolated layers. Identify requested layers, foreground occluders, joints and genuinely missing areas. Distinguish intended negative space from alpha holes. Never copy a weapon/scarf/background outline into the surface behind it.

Read the actual palette when needed: count and material ramps, no fixed 32-color assumption. Match logical resolution/integer zoom. Identify light direction, highlight/midtone/shadow transitions, outlines, texture, folds and detail density. Preserve dimensions/colors unless changes were requested. Flat replacement surfaces can violate fidelity despite a matching silhouette.

## Bound the repair
Same-work correction continues its project; distinct variant forks. Keep source and previous automatic iterations. pixel_task plan layer_completion needs brief and completion_scope=[observed existing layer IDs]. Notes record scope, never grant human permission. Do not include unrelated objects simply to mark everything complete.

Use native operations on requested layers only. Rebuild the smallest plausible hidden continuation from this material's existing ramps/geometry, behind original visible surfaces. Keep foreground intact. Validate uncertain batches. Ask for another reference when unseen shape cannot reliably be inferred; keep independent progress while waiting.

## Verify isolated and assembled views
View the full repaired layer, native size and integer zoom. Check continuity, foreign color bands, duplicate outlines, seams, stray pixels and shading. Restore composite and compare at matched scale. A matching composite DOES NOT prove hidden surfaces are sound; a nice isolated part can still damage assembly.

Mark requested parts extraction=clean, hidden=complete only after current complete isolated preview. Every completion_scope layer needs a checked record. Stale checks cannot deliver. This is AI-reported visual evidence, not automatic certification. Trial moved poses only if animation/pose testing was requested; use validation/preserved iterations. Finish inspection_workflow, existing review, save and exports. Completion does not itself authorize animation.
