# 导出到游戏引擎 / Engine export

Use the existing pixel_export tool after inspection_workflow. Saving editable .pixloom and reviewed final export remain separate steps. Changing format does not change art or invalidate current passing reviews. Review missing tags/frames first; keep the exact reviewed layer set. Explicit draft=true is still unreviewed in EVERY format.

For kind='sheet', choose sheet_format only when needed:

| sheet_format | Output | Use |
| --- | --- | --- |
| native (default) | PNG + original Pixel Loom JSON | Existing readers and projects; unchanged fields/layout |
| aseprite_hash | PNG + Aseprite JSON hash | Importers expecting frames keyed by filename |
| aseprite_array | PNG + Aseprite JSON array | Importers expecting a frames array with filename |
| godot | PNG + Aseprite hash JSON + Godot 4 SpriteFrames .tres | Native Godot animation resource; no add-on |

Call pixel_export(path='exports/actor.png', kind='sheet', sheet_format='aseprite_hash', columns=4) for an atlas. Omit tag to export all source frames; set tag='run' for one action. Layer filters preserve live visibility. Frames remain complete and untrimmed/unrotated; transparent and duplicate frames are not dropped. Integer scale changes atlas rectangles and source sizes consistently. Duration is milliseconds, tag ranges are rebased to exported frame order, reverse/pingpong direction is retained. Aseprite scale is '1' because coordinates/source sizes already describe the exported pixels. New formats require the matching backend capability engine_export_formats, not just the same application version.

Aseprite JSON is an exchange format, not an editable .aseprite project. Importer support differs by engine: do not claim built-in Godot/Unity JSON import. Aseprite repeat='1' records one-shot tags; some importers ignore repeat, so verify their animation loop settings. No colors, frames or motion are generated by export.

## Godot 4

Export sheet_format='godot'. Copy PNG and TRES together into any folder inside the Godot project; JSON can travel with them for other tools. The PNG reference is relative; no machine-specific path is embedded. Assign the TRES to AnimatedSprite2D.sprite_frames (or AnimatedSprite3D). Choose the animation name, set texture filtering to Nearest for pixel art, and play it. No plugin or extra model is needed.

Godot's PNG importer normally enables Process > Fix Alpha Border. It can change RGB in translucent glow/edge pixels even though the exported PNG is unchanged. If exact translucent RGBA values are required, select the PNG in Godot, disable Fix Alpha Border in Import, and Reimport; verify the result over the intended background. Nearest filtering alone does not disable this import processing. Pixel Loom does not overwrite an engine project's import settings.

The TRES contains AtlasTexture regions and named animations. Reverse/pingpong order is expanded once, preserving all per-frame milliseconds via relative durations at 10 FPS; do not apply a second pingpong conversion. Each action uses its inherited/overridden loop setting. An untagged project gets default; uncovered source frames get separate non-looping unnamed_N entries without overwriting real tag names. Static terrain sheets remain images; this export does not infer a TileSet grid or terrain rules. Godot 3 is not targeted.

## Save, collisions and verification

Receipts for new formats include files, metadata_path and, for godot, resource_path. PNG/sheet uses a .png path. Extra sheet formats on PNG/GIF are errors. Every bundle member needs overwrite authorization. An existing same-basename .tres blocks other sheet formats even with overwrite=true: choose another name or export godot so an old resource cannot silently reference a replacement atlas. The GUI confirms sidecar overwrite. All files are staged before replacement, with rollback on write failure; recovery errors preserve backups and report their paths.

Inspect exported PNG, JSON frame counts/regions/durations/tag ranges and engine playback. Use an actual target engine when available; otherwise say that engine verification is incomplete. Do not weaken reviews to export and do not call a syntactically valid JSON an artistic or engine-import pass. Save after review to keep portable conclusions. No automatic publishing or installation.
