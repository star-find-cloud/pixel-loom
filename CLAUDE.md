# Pixel Loom

Read this directory's `README.md` first, then call `pixel_onboard` to verify a real MCP connection.
Preserve existing artwork. Convert faithfully and separate visible objects into editable layers; no unrequested hidden completion, artistic redesign or animation. Start with compact onboarding and follow the selected MCP task guide; opening/importing alone starts no editing task.
For application development, the complete source and formal tests are in `project/`; follow `project/AGENTS.md` and work from that directory.
